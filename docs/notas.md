## Changelog

- Pantalla de bienvenida en el primer arranque: eliges las carpetas de Usuario y de ROMs y escanea los sistemas al continuar.
- Configuración navegable con el mando, con desplegables propios; la sección Sistemas es ahora una lista con las opciones del sistema elegido al lado.
- Opción para guardar las credenciales de ScreenScraper y SteamGridDB en la Carpeta de Usuario (desactivada por defecto, con aviso).
- Scrapper con animación de descarga y fundido entre juegos; escaneo de un solo sistema desde Configuración.
- «Cerrar» (B) en la lista de Sistemas, con confirmación; fundido entre Sistemas y Juegos; logos de sistema más rápidos al arrancar.
- `ginny.cfg` comparte tema y favoritos, y conserva las claves que no conoce; las carpetas de ROMs ahora son propias de cada dispositivo.

### Instalación
Descarga el APK y ábrelo en el dispositivo (hay que permitir "instalar apps desconocidas"). Necesitas un emulador instalado para lanzar juegos.
